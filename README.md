# 3X Sports Arena — Next.js Booking & Management Platform

A high-performance, modern web application and management operating system built for **3X Sports Arena**, Jail Road, Lahore.

Built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **Lucide Icons**.

---

## 🌟 Key Features

- **Cinematic Video Hero:** Real-time looping background video (`hero.mp4`) with aerial drone video tour modal.
- **Dedicated Multi-Page Architecture:**
  - `/` (Home page with live open slots, court previews, and interactive FAQs)
  - `/courts` (Complete playing surfaces specifications: Artificial Turf Rs 2,500/hr, Natural Grass Rs 2,200/hr, Pro Futsal Rs 2,500/hr)
  - `/pricing` (Transparent rate card, 40% daytime discounts, 30% advance deposit terms, and cancellation policies)
  - `/facilities` (Live BBQ cafe, floodlight specifications, equipment, washrooms, and parking)
  - `/gallery` (Filterable photos with full-screen lightbox + inline 4K drone video player)
  - `/about` (The story of 3X Sports Arena, values, and location)
  - `/contact` (Phone lines, 1-tap WhatsApp button, and interactive inquiry form)
  - `/my-booking` (Self-service customer reservation lookup by phone or booking ID)
  - `/book` (4-step interactive slot booking flow with confetti celebration and instant WhatsApp receipts)
  - `/admin` (Split-screen staff login page, left sticky sidebar navigation, 24h court matrix, walk-in creation, and finance cash-up)

---

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Custom Dark Obsidian & Crisp White surface cards)
- **Animations:** Framer Motion (Scroll reveals, accordion expansion, hover elevations)
- **Icons:** Lucide React
- **Confetti:** Canvas-Confetti

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3005](http://localhost:3005) (or [http://localhost:3000](http://localhost:3000)) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
